          Ayuda

          ¿Qué es la planificación automática STRIPS?

          Guía rápida

          La planificación automática busca una secuencia de acciones que transforme un estado inicial en un estado objetivo. En STRIPS, cada acción se describe mediante precondiciones y efectos.

          1

          Define inicio y meta

          Selecciona la celda donde inicia el robot y la celda objetivo.

          2

          Genera el plan

          El sistema evalúa las acciones posibles y usa BFS para encontrar una ruta válida de movimientos.

          3

          Interpreta STRIPS

          PRE indica lo que debe cumplirse, ADD lo que se agrega y DEL lo que se elimina del estado.

          4

          Simula paso a paso

          Usa Reproducir, Pausar, Avanzar o Reiniciar para observar cómo cambia el estado del robot hasta alcanzar la meta.

          Instrucciones de uso

          1. Selecciona Inicio y Meta. Elige dos celdas de la cuadrícula 4×4.
          2. Pulsa Generar plan STRIPS. La app calculará una secuencia válida de movimientos.
          3. Revisa la ruta. Observa movimientos, estados expandidos y acciones del plan.
          4. Usa Avanzar. Ejecuta una acción y revisa PRE, ADD, DEL y el cambio de estado.
          5. Usa Reproducir o Pausar. Ejecuta automáticamente el plan o detén la simulación.
          6. Usa Reiniciar. Devuelve el robot al estado inicial para repetir la simulación.

          Regla de transición: S′ = (S − DEL) ∪ ADD

          Modelo utilizado

          5. Regla de transición

          Una acción es aplicable cuando sus precondiciones se encuentran en el estado actual. Después, STRIPS elimina los efectos DEL y agrega los ADD.

          S′ = (S − DEL) ∪ ADD
